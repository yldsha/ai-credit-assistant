# Alfa SME Credit Pipeline MVP

Микросервисное приложение для автоматизации конвейера кредитных заявок малого и среднего бизнеса. Включает в себя скоринговую ML-модель, систему принятия решений (Decision Engine) и имитацию внешних API.

## Требования
Для локального запуска не нужно устанавливать Python или Node.js. Потребуется только:
* [Docker Desktop](https://www.docker.com/products/docker-desktop/) (или OrbStack)
* Git

## Быстрый запуск

1. Склонируйте репозиторий на свой компьютер:
```bash
git clone [https://github.com/yldsha/ai-credit-assistant.git](https://github.com/yldsha/ai-credit-assistant.git)
cd ai-credit-assistant
```

2. Соберите и запустите микросервисы одной командой:
```bash
docker compose up --build
```
*(Первый запуск займет пару минут, пока скачаются нужные образы и установятся зависимости).*

## Точки входа

Как только в терминале появится сообщение об успешном старте всех сервисов, откройте ссылки в браузере:

* **Клиентский и рабочий интерфейс (Frontend):** http://localhost:5173
* **Документация API Бэкенда (Swagger):** http://localhost:8000/docs
* **Документация API внешних источников (Mocks Swagger):** http://localhost:8001/docs

## Важная информация для тестирования

* **База данных:** Используется легкая локальная база SQLite. Файл `app.db` создается и заполняется базовыми демо-данными автоматически при первом запуске бэкенда.
* **Авторизация:** В систему уже вшиты демо-клиент и демо-сотрудник (андеррайтер). Дополнительная регистрация не требуется, переключение ролей доступно прямо в интерфейсе.
* **Внешние источники:** Запросы к ЕГРЮЛ, ФНС и БКИ обрабатываются локальным микросервисом `mocks`. Он работает по сети, имитируя задержки и ответы реальных государственных баз данных.
