# Roadmap развития продукта

## Умный кредитный кабинет предпринимателя

## 1. Цель развития

Основная цель — создать удобный цифровой сервис для кредитования малого и среднего бизнеса, который позволяет автоматизировать обработку заявок, сократить время принятия решений и снизить нагрузку на сотрудников банка.

## 2. Текущее состояние MVP

В проекте предусмотрены:

- Клиентский кабинет для подачи и отслеживания заявок.
- Интерфейс сотрудника банка.
- Подбор кредитных продуктов.
- ML-скоринг для оценки вероятности дефолта (PD).
- Decision Engine для принятия кредитных решений.
- Имитация проверок через ЕГРЮЛ, ФНС и БКИ.
- Хранение заявок и истории изменения статусов.

**Основные ограничения:** используются синтетические данные, внешние интеграции имитируются, а реальные банковские операции не выполняются. Сквозную работу frontend и backend необходимо подтвердить тестированием.

## 3. Этапы развития

| Этап | Основные задачи | Ожидаемый результат |
|---|---|---|
| 1. Стабилизация MVP | Проверка семи тестовых сценариев, исправление ошибок, синхронизация frontend и backend | Работоспособный кредитный конвейер |
| 2. Оптимизация скоринга | Анализ PD, подбор порогов одобрения и отказа | Повышение качества автоматических решений |
| 3. Контроль SLA | Учёт времени обработки, выявление просроченных заявок | Соблюдение сроков рассмотрения |
| 4. Продуктовая аналитика | Расчёт конверсии, доли автоматических решений и ручного разбора | Оценка эффективности продукта |
| 5. Развитие системы | Улучшение интерфейсов, безопасности и интеграций | Подготовка к масштабированию |

## 4. Приоритеты

| Приоритет | Задачи |
|---|---|
| P0 — критический | Исправление ошибок и проверка сквозного процесса |
| P1 — высокий | Оптимизация PD, контроль SLA, сбор метрик |
| P2 — средний | Улучшение интерфейса и автоматизация тестирования |
| P3 — долгосрочный | Реальные интеграции и масштабирование инфраструктуры |

## 5. Целевые показатели

| Метрика | Предварительная цель |
|---|---|
| Доля автоматических решений | ≥ 75% |
| Время автоматического решения | ≤ 2 минуты |
| Доля ручного рассмотрения | 15–20% |
| Конверсия в отправленную заявку | ≥ 75% |

Показатели являются целевыми ориентирами. Их достижение необходимо подтвердить фактическими измерениями.

## 6. Ожидаемый результат

Реализация дорожной карты позволит повысить скорость и прозрачность кредитного процесса, сократить количество ручных операций и улучшить пользовательский опыт предпринимателей.

Главный приоритет — обеспечить стабильную работу MVP, после чего перейти к оптимизации кредитных решений, контролю SLA и развитию продуктовой аналитики.
